## 🔧 Para Compilar Localmente

Si quieres compilar en Windows:
1. Instala DevKitPro con devkitA64
2. export DEVKITPRO=C:\devkitpro
3. cd GREENLIGHT_SWITCH
4. bash build.sh

O manualmente:
  mkdir build && cd build
  cmake ..
  make
